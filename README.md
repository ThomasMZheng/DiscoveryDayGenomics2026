# Investigating Proteomics

**QLS Discovery Day × McGill Initiative in Computational Medicine (MiCM)**  
**Date:** November 20, 2026 · **Instructor:** Thomas Zheng · **Format:** 45-min workshop + 15-min Q&A

## Workshop overview

We will be looking at protein samples from human blood plasma! This is a segment from https://github.com/QLS-MiCM/Proteogenomics

## Prerequisites

- No previous proteomic or genetic training required; basic R is very helpful but is not essential so long as you have other coding experience.
- A laptop with a browser and internet access for **Google Colab**.
- Basic familiarity with running a notebook cell is helpful. No GPU needed.
- Dataset and code are small (~5 MB plus dependencies).

## Structure

Unlike most workshops - we only have 45 minutes so we'll go through a quick powerpoint before getting our hands on some code!
